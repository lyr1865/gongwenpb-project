# 📝 公文自动排版工具

> 一款基于 GB/T 9704 国标的党政机关公文在线排版工具。

## ✨ 功能特点
- **在线排版**：直接在浏览器中运行，无需安装任何软件。
- **标准规范**：严格遵循 GB/T 9704 标准。
- **实时预览**：所见即所得，排版效果一目了然。
- **智能分页**：自动处理页面布局。
- **DOCX 导出**：支持一键导出为 Word 文档。
